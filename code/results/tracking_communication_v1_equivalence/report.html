Cost records contain client ID, trial ID, public gain/context input ID and float64 J (20 bytes). Peer records also carry the source-mode code (24 bytes). Actual 16-byte packet headers and every recipient delivery are charged. The historical dense-model and 12-byte peer numbers were analytical payload references, so their sum is not a measured network baseline. The same-catalogue column combines the old model estimate with the new peer application traffic to isolate the cost-channel change. IP/TLS, routing, acknowledgements, retries and public-design provisioning are excluded. The final unused flush is separate in traffic.csv.

The coordinator relays records; every recipient reconstructs the same exact shared/local posterior. A repeated public input from a different client remains a separate observation. Failed-test labels remain private. This audit establishes representation equivalence for the frozen programmes; it makes no new control-performance claim.
