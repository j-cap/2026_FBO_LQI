Online fleet calibration from empty histories

All methods start without calibration observations or a learned catalogue. Fresh nonlinear rollouts are generated only when queried. Every query counts, including initialization, failures, and scout/follower verification. Physical dynamics, controller, objective and the 71-point gain pool match the frozen tracking diagnostic.

The five concurrent methods share one factory-gain test per client. They adapt from round 2, even if no locally eligible incumbent exists. All BO decisions minimize mu - 2 sigma - log(max(1e-6, p_eligible)) on log J. Gain sharing can request a peer incumbent from round 2; its BO fallback uses the same acquisition. The scout starts with one factory test, adapts immediately, and preserves its separate waiting/verification procedure. Context schedules and client/query noise are paired across methods. Each complete context cycle visits all six references once. Round-t outcomes become shareable only after all round-t actions are frozen.

What each comparison identifies

Independent GP BO versus local-cost BO checks the local learned-mean pipeline. Federated versus local-cost BO tests sharing beyond the same cost model trained locally. Gain sharing tests a simpler online library. Single scout tests learning on one vehicle followed by target verification and repair. Centralized uses an exact ridge fit of the same fixed-feature regression objective; it is an information/optimization reference, not a required empirical upper bound.

Time and communication accounting

Parallel calibration rounds and total experiments are separate metrics. Scout followers wait during scout search, then verify its frozen catalogue and adapt locally. They eventually receive the same local query cap as other methods. Payload bytes are float64 model-vector estimates or declared record/incumbent payloads; they exclude transport overhead. No bandwidth advantage or formal privacy guarantee follows from this simulation.

Scope

This is a three-seed development pilot on fixed plants, with independent fresh client/query noise streams. It is not independent-fleet confirmation. Homogeneous clients have identical physical parameters, but different noise and context programmes. The validation bank uses the two frozen independent noise repeats; homogeneous clones share that evaluation bank. The dense empirical reference and validation records are evaluator-only. No held-out shapes, continuous gain optima, certified safety, or real-world commissioning protocol is established.

The learned mean is empirical Bayes: it can include the target's own queried records. Shared predictions are not inserted as extra observed trials. Residual GP uncertainty and feasibility weights are working surrogates, not calibrated certificates. This changes both initialization and acquisition relative to the frozen six-test pilot, so an across-pilot difference cannot isolate either change alone. See docs/tracking_online_lcb.md.
