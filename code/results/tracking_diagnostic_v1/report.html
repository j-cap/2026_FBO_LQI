Trajectory-tracking diagnostic

Finite-pool diagnostic with true nonlinear plants. All controller selections use calibration seeds only; tables use independent validation noise. Exact-model similarity descriptors are oracle diagnostics. No BO or federated benefit is claimed.

J = RMSE(e_y)/0.25 m + RMS(applied steering rate)/(10 deg/s). Coverage is shown before cost. Fleet mean is unavailable if any cell is ineligible; conditional means must not be compared across unequal coverage. Failed and numerically unresolved trials remain in the CSV files.
