Budgeted trajectory-tracking calibration

Retrospective finite-pool replay: all physics rollouts already exist. Learners reveal only requested target calibration observations. Validation noise and dense reference values are read after query traces have been frozen. This is a historical-transfer benchmark; it does not implement networked federation or a privacy guarantee.

Budgets count individual 25-second target rollouts across all six reference contexts. One archived calibration-noise realization is used per optimizer seed. The fixed catalogue spends six verification rollouts and stops; its curve stays flat at larger allowances. Each historical source has 852 calibration rollouts. This is an explicitly data-rich historical scenario.

Context success requires a feasible recommendation within 5% of its calibration-selected finite-pool reference on independent validation noise. Recommendations must have been observed feasible during target calibration. Missing incumbents and failed validations count as unsuccessful contexts. All-context success requires all six contexts to succeed. Rollout feasibility is not a stability certificate.

Interpretation limits

These nine deterministic plants, two calibration-noise realizations, and optimizer seeds are not independent population samples. No pooled-pair significance claim is made. The 71-candidate pool and original search-boundary limitations remain. New shapes, 25 m/s performance and sparse source histories are not evaluated by this replay. The deterministic v2 reference assignment audit is saved separately; the original v1 trajectories and results are unchanged.

Before designing a more complex method, inspect whether either BO variant provides useful improvement over the source catalogue and whether pooling increases failed commissioning trials. See docs/tracking_budget.md for the complete frozen protocol.
